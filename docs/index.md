# Journal Notes

A private journal and a separate Notes app for study, for Linux
(GTK 4). Everything is kept on your own computer.

- **Journal:** one page per day, encrypted, with a PIN or passphrase.
  It never goes online.
- **Notes:** subjects, topics and study sessions, a study timer, export
  to Markdown, an optional AI enhanced copy, and an optional backup to
  your own Google Drive as Google Docs (it can see only the files it
  made).
